A real chess engine in 4,096 bytes of Python for make.fun's tiny-chess-01: 0x88 board, principal variation search with late-move reduction, quiescence, transposition table, two killer moves per ply, tapered PeSTO evaluation, iterative deepening to a fixed 40,000-node budget per move. No book, no clock, no randomness — every trial replays identically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
